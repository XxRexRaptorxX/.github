# XxRexRaptorxX - GitHub Community Files

Welcome to the central GitHub community repository for my Minecraft mods and projects.

This repository contains shared templates, guidelines and resources used across my GitHub repositories to ensure consistent issue reporting, contributions and community support.

## 📋 Issue Templates

When reporting bugs or suggesting new features, please use the appropriate issue template in the respective mod repository.

### 🐛 Bug Reports
Found a bug or unexpected behavior?

Please create a Bug Report and provide all relevant information, including:
- Minecraft version
- Mod version
- Mod loader and version
- Launcher
- Java version
- Additional installed mods
- Steps to reproduce the issue
- Relevant logs or crash reports

[How to report an issue correctly](https://github.com/XxRexRaptorxX/General/blob/main/how_to_report_an_issue_correctly.md)

### 💡 Feature Requests
Have an idea for a new feature or improvement?

Use the Feature Request template to describe:
- Your feature idea
- The problem or use case it addresses
- Your proposed solution
- Possible alternatives or additional context

Please check existing issues before submitting a new request.

## 📖 Guidelines

The following guidelines and resources are intended to help maintain consistent standards across my projects.

- **Bug Reporting:** Follow the issue reporting guide before submitting a bug.
- **Feature Requests:** Explain the purpose and expected behavior of your suggestion.
- **Issue Discussions:** Keep discussions relevant, constructive and respectful.
- **Reproducibility:** Provide enough information to reproduce reported problems.
